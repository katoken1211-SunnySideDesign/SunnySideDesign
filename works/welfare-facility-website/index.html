群馬県内の介護施設Webサイト制作

施設の理念やサービス、日々の暮らしの様子を、ご本人とご家族へ安心して確認していただけるWebサイトへ。企画・撮影からデザイン、実装、公開まで一貫して担当しました。

DirectionPhotographyLogo DesignWeb DesignDevelopment2026

Project

群馬県内で有料老人ホーム・デイサービス・訪問介護を運営する介護施設のWebサイトを制作しました。これまで施設独自のホームページがなく、特徴やサービス、施設での暮らしを十分に伝えられていないことが課題でした。

Category

介護施設 / Corporate Website

Scope

Direction / Photography / Logo / Design / Development

Year

2026

施設の許可を得たうえで、制作内容を掲載しています。

課題

  • 検索した際に施設独自の十分な情報が表示されない
  • 有料老人ホーム・デイサービス・訪問介護、それぞれの違いが伝わりにくい
  • 入居を検討する方やご家族が、施設の雰囲気を事前に確認できない
  • 小規模施設ならではの距離の近さや温かさが、Web上で表現されていない
  • 見学や利用相談につながる窓口を、分かりやすく整備する必要がある
  • プライバシーに配慮しながら、施設の実際の様子を伝える必要がある

ヒアリング

「その人らしく生きる」という理念を、サイトの軸に。

経営者・施設スタッフへのヒアリングを行い、施設の現状や今後の方向性、日々の支援で大切にしている考えを整理しました。

特に重視したのは、「人が人として、その人らしく生きること」という理念です。利用者を一方的に守られる存在として捉えるのではなく、スタッフや地域の方を含め、お互いに支え合う対等な関係性を大切にしていることが分かりました。

小規模な施設だからこそ、一人ひとりの表情や体調の変化に気づける距離感があること、本人だけでなくご家族にも安心してもらえる場所を目指していることを伺い、機能や設備だけでなく施設の人柄や空気感まで伝わる構成を目指しました。

Concept

やさしさに包まれる、安心の暮らし。

白と淡いピンクを基調に、温かさと清潔感を両立。情報を詰め込みすぎず、ご本人、ご家族、介護・医療関係者が目的のページへ迷わず移動できる情報設計にしました。

施設の設備を説明するだけでなく、そこで過ごす時間と、支える人の姿勢が感じられるサイトへ。

Design

COLOR

やさしさと清潔感

白と淡いピンクを軸に、施設の温かい雰囲気と安心感を表現しました。

PHOTOGRAPHY

生活を想像できる写真

外観・居室・共有スペース・周辺環境を撮影。人物の顔を掲載せず、暮らしをイメージできる構成です。

TYPOGRAPHY

読みやすく、穏やかに

理念を伝える見出しには品のある表情を持たせ、本文は幅広い閲覧者に読みやすく整えました。

UI

迷わない導線

施設紹介、サービス、利用案内、アクセス、相談窓口を分かりやすく整理しました。

MOBILE

スマホ専用の最適化

ヒーロービジュアルとナビゲーションを端末に合わせて調整し、押しやすさにも配慮しました。

PRIVACY

プライバシーへの配慮

施設の実像を伝えながら、スタッフや利用者の顔が映らない写真を選定しました。
